# 重生短剧按键挂件 · rebirth-drama-pad

> 一个**离线、单文件**的短剧按键音效挂件：手机浏览器直接打开 `file://` 就能用，一按就有 BGM 梗。

![试玩版](assets/screenshot-demo.png)

## 这是什么

把「短剧梗音效」做成挂在钥匙圈上的按键挂件：点圆环就响、再点停止、切歌有交叉淡化，
背景是跟着挂件图自动配色的毛玻璃。全部逻辑打包进**一个 HTML 文件**——
不联网、不需要服务器、不需要装 App。

## 三个文件

| 文件 | 大小 | 作用 |
| --- | --- | --- |
| `试玩版.html` | 247 KB | **成品长相**。两张挂件图与 6 个按键热区已内嵌，打开即见最终形态，底部可切换男主款 / 女主款。声音由浏览器现场合成，只为试手感。 |
| `打包器.html` | 443 KB | **音频合成器**。选歌 → 分配到 12 个按键 → 看体积红线 → 生成成品 HTML。自带本地 MP3 压缩（可选码率 / 声道 / 采样率）。 |
| `MP3压缩器.html` | 165 KB | 独立小工具，只管压 MP3，不管挂件。 |

三个都是**单文件、离线、`file://` 直开**，安卓 + PC 通用。

## 快速开始

1. 下载 `试玩版.html` 传到手机，用**文件管理**打开 →「打开方式」→ **Chrome**。
2. 点圆环听声音，点底部按钮切换男主款 / 女主款。
3. 想做正式成品：在电脑上打开 `打包器.html`，把 mp3 拖进歌曲库，分配到按键，生成下载。

> - 手机上别用系统自带的「HTML 查看器」（只显示源码不出声）；微信 / QQ 里直接点开也不行，要先存到本地。
> - 首次出声必须**用手指点**按键（浏览器规定音频要由用户操作触发，进页面不会自动响）。
> - 想常驻就浏览器菜单 →「添加到主屏幕」。

## 换挂件图与对位

`打包器.html` 第 2 节可以**换挂件图**：支持 **GIF、动图 WebP** 等会动的图，成品里原样内嵌、不重新编码，动画保留。
换完在图上**直接拖动 6 个圈**对位到挂件圆环上；坐标按图片宽高的**百分比**记录，所以换成 800px 或 4000px 的图都不会跑位。
选中某个圈还能单独改直径（把最常用的键做大一点更好按）。不碰这一节就完全沿用默认。

## 从源码构建

```powershell
python .build\build.py                 # 重建 打包器.html + 试玩版.html（自带结构自检）
python .build\build_compressor.py      # 重建 MP3压缩器.html
node --check .work\check_packer.js     # 构建会把脚本块抽出来供语法检查
node tests\test_player.js              # 播放器功能
node tests\test_v2.js                  # 按键对位 / 每键直径
node tests\test_packer_compress.js     # 压缩流水线
python tests\verify_final.py           # 端到端：从产物解图/热区，与打包器常量比对（需 Pillow）
```

- `打包器.html` / `试玩版.html` / `MP3压缩器.html` 是**产物，不要手改**，重建会覆盖。
- 唯一真源：`.build/player.css`、`.build/player.body.html`、`.build/player.js`（播放器），
  `.build/packer.tpl.html`（打包器模板），`.build/compressor.tpl.html`（压缩器模板）。
- 版本号只写在 `.build/build.py` 的 `VER`，重建后四个落点自动同步。
- 默认挂件图在 `assets/`；构建脚本的路径全部由脚本自身位置推导，**不含绝对路径**，克隆到任意目录都能直接跑。

设计取舍、实测数据、踩过的坑见 [`说明.md`](说明.md)。

## 体积红线

成品 **≤ 30MB**。打包器会实时显示已放几首、成品预计多大、还剩多少、单首上限，并有一条进度条；
超限变红并弹确认框（红线是硬警告，不是拦路石）。
内嵌 base64 有 **1.37 倍**膨胀，无法避免；体积几乎全由音频决定，图片只占约 170KB。

## 音频素材

本仓库**不包含任何歌曲**，也不包含内嵌了真实歌曲的成品（见 `.gitignore`）。
`试玩版.html` 的声音是现场合成的，不需要音频文件；打包器需要你自己提供 mp3。

## 已知限制

- **按键上没有文字**，靠下方「当前音效：XXX」那行辨识；第一次基本是在试，之后靠记位置。
- mp3 有编码头尾，循环**不是绝对无缝**，每圈可能有极短静音。
- **切换款时会立刻停掉正在响的声音**，不会跨款继续播（不这么做会留下停不掉的幽灵音频）。
- 切键有约 **120ms 交叉淡化**，那一瞬间有极短双声重叠（防爆音的有意设计）。
- 切到后台可能被系统暂停，安卓省电策略所致。
- `ogg / opus / flac / webm` 在部分国产浏览器上不出声，建议统一用 mp3。
