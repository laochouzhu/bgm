重生短剧按键挂件 · 音频合成器 {{VER}}

挂件图和 6 个按键的位置已经钉死在成品里了，这个工具只管三件事：选歌、本地压缩、卡住体积红线。

1当前挂件图（默认）

男主款 · 蓝 女主款 · 粉

2挂件图与按键对位

换图

图上的六个圈可以直接拖动到挂件的圆环上（鼠标和手指都行）；选中某个圈后拖上面的滑杆改直径。取消勾选「六个一起改大小」就能单独调某一个。

支持 GIF / 动图 WebP 等会动的图（成品里会原样内嵌，不重新编码，所以动画保留）。不换图、不动坐标，就和默认完全一样；换了图记得重新对位。

成品页面底色是纯黑，图片保持原样显示。想要挂件"悬空"的效果，就换成透明底的 PNG / WebP / GIF。

3歌曲库（可批量拖拽）

同一首歌可以分给多个按键，只会内嵌一次，不额外占体积。加进来的歌会自动填到第一个空位。

压缩用内嵌的 lamejs 在本地完成（不联网、不上传）。已经够小的文件会自动跳过压缩，避免无谓的音质损失。

7怎么放到手机上

  1. 生成得到 重生短剧按键挂件.html 一个文件。
  2. 传进手机（微信文件传输助手 / QQ / 数据线 / 网盘都行）。
  3. 在手机的文件管理里找到它，点「打开方式」→ 选 Chrome 或你常用的浏览器。
  4. 打开后点挂件上的圆环出声；想常驻就浏览器菜单 →「添加到主屏幕」。

两个坑：① 别用系统自带的「HTML 查看器」，它不会响；② 微信里直接点开也不行，必须先存到文件管理再打开。
